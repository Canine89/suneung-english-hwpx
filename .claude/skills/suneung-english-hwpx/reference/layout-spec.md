# 수능 영어 영역 문제지 양식 실측값

2026학년도 수능 영어 영역 문제지(평가원 공개 PDF, A3 842×1191 pt, 1–8쪽 홀수형)를 PyMuPDF로 잰 값이다.
`tools/build.py` 상단 상수가 이 값을 쓴다. 단위 pt (1 pt = 100 HWPUNIT). 문항 위치 목표는 빌드 때마다
`tools/measure.py` 로 원본에서 직접 읽는다(`build/target.json`).

## 줄 맞춤 관행
원본도 한 줄에 맞추려고 문단별 자간을 줄인다(예: 4번 발문 한글 폭 9.5, 공백 4.2). 우리 글에서 한두 낱말이
넘치면 `{"sp": -10~-15}` 로 같은 방식을 쓴다.

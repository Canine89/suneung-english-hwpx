# 샘플 — 이 스킬로 만든 모의 문제지 2회분

두 회차 모두 2026학년도 수능 영어 홀수형 **양식**(8쪽 2단, 문항 위치·글꼴·상자)을 따르고,
문항·지문·듣기 대본은 모두 새로 출제했습니다. 평가원 문항은 들어 있지 않습니다.

| 폴더 | 내용 | 만든 방식 |
|---|---|---|
| `2027-모의1/` | 1회 (예: 21번 측정 지표, 41–42번 바람직한 어려움, 43–45번 새집 만들기) | 조판을 돌려 가며 분량을 맞춘 첫 회차 |
| `2027-모의2/` | 2회 (예: 21번 a museum of good intentions, 41–42번 실수 효과, 43–45번 자전거 고치기) | **분량 예산표 → `budget.py check` → 조판 1회** 절차로 만든 회차. 새 회차를 쓸 때 이 `exam.py` 를 출발점으로 쓰는 것을 권장 |

## 폴더마다 있는 파일
- `output/영어영역_문제지.pdf`, `.hwpx` — 결과 문제지 (한글 2024에서 저장)
- `output/정답표.txt` — 정답·배점 (①~⑤ 각 9개, 합 100점)
- `output/듣기대본.txt` — 1~17번 듣기 대본 (음원 없음)
- `exam.py` — 문제지 원고 데이터. 블록 형식은 파일 맨 위 설명 참고.
  2회 파일에는 회차별 자체 점검(`ORDER_KEY`, `self_checks()`, `FIG_TEXT`)이 들어 있다(1회는 그 이전 형식).
- `figures/` — Codex가 image gen으로 만든 듣기 4번 그림·25번 도표, 그림 사양서(`FIGURE_SPEC.md`),
  제작·검수 기록(`DONE.txt`), image gen 프롬프트(`src/prompts.json`)
- `codex_solve.txt` — Codex가 정답 없이 푼 교차 풀이 결과(두 회차 모두 45문항 정답과 일치)

## 검증 결과
- 문항 번호·묶음 지시문 등 56개 위치: 원본 PDF와 0.1 pt 이내
- 형식 점검(`verify.py`): 구성·배점·정답 분포·유형 구조·계산 문항 통과
- 교차 풀이: 45/45 일치. 1회 39번은 Codex 이의(삽입 위치 유일성)를 받아 문장을 고친 뒤 확정

# 그림 사양서 — 2027 모의 영어 영역 (홀수형)

요청자: Claude Code (왼쪽 패널) / 작업자: Codex (오른쪽 패널)
**두 그림 모두 image gen(이미지 생성 도구)으로 만든다.** matplotlib 같은 코드 플로팅으로 대신하지 않는다.

## 공통 저장 규칙
- `figures/<파일이름>.png`, **600 dpi, 흰 배경**(투명 금지), 바깥 여백 1 mm 안팎으로 잘라냄
- 가로 픽셀 = 인쇄 폭(mm) ÷ 25.4 × 600
- 프롬프트는 `figures/src/prompts.json`, 원본 이미지는 `figures/src/raw/` 에 보관
- 끝나면 `figures/DONE.txt` 에 그림별 실제 크기(mm, px)와 남은 오차를 적는다.
- `problems/`, `tools/`, `output/`, `build/` 는 수정하지 않는다.

## 1. `fig_l04.png` — 듣기 4번 그림 (대화 내용과 일치하지 않는 것 고르기)

- 인쇄 크기: **가로 108 mm × 세로 66 mm** (가로:세로 ≈ 1.64:1). 가로 2551 px.
- 스타일: 수능 영어 듣기 4번 그림처럼 **흑백 선화(펜 드로잉)**. 회색 음영은 최소, 컬러 금지.
  선은 깔끔하고 균일하게, 만화풍 과장 없이 단순한 삽화체. 사람은 그리지 않는다.
  그림 전체를 가는 검은 테두리(사각형)로 두른다.
- 장면: **숲속 캠핑장**(낮). 왼쪽에서 오른쪽으로 다음 다섯 요소가 겹치지 않게 배치하고,
  각 요소 바로 옆에 **원문자 번호 ①②③④⑤** 를 작은 글씨(검정, 정체)로 붙인다.
  1. ① 두 나무 사이에 걸린 **현수막**, 글자 **"CAMP"** (대문자, 또렷하게 읽힐 것)
  2. ② **돔 텐트** — 텐트 천에 **별(★) 무늬** 여러 개
  3. ③ **둥근 탁자** 위에 **랜턴 하나**
  4. ④ 나무에 기대어 세워 둔 **자전거 한 대** (반드시 1대. 2대 금지)
  5. ⑤ 매트 위에 **엎드려 자고 있는 강아지** 한 마리
- 배경 요소(나무, 풀, 먼 산 등)는 단순하게, 번호가 붙은 다섯 요소가 눈에 잘 띄게.
- 검수 포인트: "CAMP" 철자, 텐트의 별 무늬, 탁자가 둥근지, 랜턴 1개, **자전거 1대**, 강아지가 매트 위에서 자는지, 번호 ①–⑤ 위치.

## 2. `fig_r25.png` — 25번 도표 (가로 막대그래프)

- 인쇄 크기: **가로 103 mm × 세로 70 mm** (가로:세로 ≈ 1.47:1). 가로 2433 px.
- 스타일: 수능 영어 25번 도표 양식. **흑백**(검정 + 회색 2단계), 글꼴은 Times New Roman 계열 세리프.
  격자·그림자·3D 효과 없음. 그래프 전체를 가는 검은 테두리 사각형으로 두른다.
- 제목(그래프 위, 가운데, 굵게, 2줄 허용):
  **Preferred News Sources among Teenagers in 2016 and 2026**
- 범례(오른쪽 위, 작은 상자): 진한 회색 막대 = **2016**, 연한 회색(빗금 없이) 막대 = **2026**
- 세로축(왼쪽)에 범주 5개, 위에서 아래 순서, 범주마다 막대 2개(위 2016, 아래 2026):

  | 범주 | 2016 | 2026 |
  |---|---|---|
  | Social Media | 32 | 45 |
  | Video Platforms | 18 | 30 |
  | News Websites | 24 | 12 |
  | TV | 20 | 10 |
  | Print Newspapers | 6 | 3 |

- 가로축: 0, 10, 20, 30, 40, 50 눈금 숫자, 축 끝에 **(%)** 표시. 막대 길이는 위 수치에 **정확히 비례**.
- 각 막대 오른쪽 끝에 수치를 작은 숫자로 표기(32, 45, 18, 30, 24, 12, 20, 10, 6, 3).
- 검수 포인트: 범주 이름 철자, 10개 수치 라벨, 막대 길이 비율(예: 45 막대 = 3 막대의 15배, 30 = 18의 1.67배), 범례 색 구분.

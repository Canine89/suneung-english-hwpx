# 그림 사양서 — 2027 모의 영어 영역 2회 (홀수형)

요청자: Claude Code (왼쪽 패널) / 작업자: Codex (오른쪽 패널)
**두 그림 모두 image gen(이미지 생성 도구)으로 만든다.** matplotlib 같은 코드 플로팅으로 대신하지 않는다.
(1회 그림은 `archive/2027-모의1/figures/` 에 있다. 같은 파일 이름으로 새로 만든다.)

## 공통 저장 규칙
- `figures/<파일이름>.png`, **600 dpi, 흰 배경**(투명 금지), 바깥 여백 1 mm 안팎으로 잘라냄
- 가로 픽셀 = 인쇄 폭(mm) ÷ 25.4 × 600
- 프롬프트는 `figures/src/prompts.json`, 원본 이미지는 `figures/src/raw/` 에 보관(1회 것은 덮어써도 됨, 보관본 있음)
- 끝나면 `figures/DONE.txt` 를 새로 쓴다(그림별 실제 크기 mm·px, 남은 오차).
- `problems/`, `tools/`, `output/`, `build/` 는 수정하지 않는다.

## 1. `fig_l04.png` — 듣기 4번 그림 (대화 내용과 일치하지 않는 것 고르기)

- 인쇄 크기: **가로 108 mm × 세로 66 mm** (가로:세로 ≈ 1.64:1). 가로 2551 px.
- 스타일: 1회와 같은 **흑백 펜 선화**, 회색 음영 최소, 컬러 금지, 사람 없음. 그림 전체를 가는 검은 사각 테두리로 두른다.
- 장면: **학교 과학 축제 부스**(실내, 정면에서 본 모습). 다섯 요소가 겹치지 않게 배치하고,
  각 요소 바로 옆에 **원문자 번호 ①②③④⑤** 를 작은 글씨(검정, 정체)로 붙인다.
  1. ① 부스 위에 가로로 걸린 **현수막**, 글자 **"SCIENCE FAIR"** (대문자, 또렷하게)
  2. ② 탁자를 덮은 **체크무늬(바둑판무늬) 식탁보** — 반드시 체크무늬. 꽃무늬·줄무늬 금지
  3. ③ 탁자 위의 **화산 모형** (원뿔 모양, 꼭대기에서 연기 몇 줄)
  4. ④ 탁자 아래 바닥에 놓인 **화분 두 개** (반드시 2개)
  5. ⑤ 부스 뒤 벽(게시판)에 붙은 **태양계 포스터** (태양과 궤도 위 행성 몇 개)
- 검수 포인트: "SCIENCE FAIR" 철자, 식탁보가 체크무늬인지, 화산 모형, 화분 2개, 태양계 포스터, 번호 ①–⑤ 위치.

## 2. `fig_r25.png` — 25번 도표 (세로 막대그래프)

- 인쇄 크기: **가로 103 mm × 세로 70 mm** (가로:세로 ≈ 1.47:1). 가로 2433 px.
- 스타일: 1회와 같은 수능 영어 도표 양식. **흑백**(진한 회색·연한 회색), Times New Roman 계열 세리프,
  격자·그림자·3D 없음, 그래프 전체를 가는 검은 사각 테두리로 두른다. **이번에는 세로 막대**(묶음 막대).
- 제목(위, 가운데, 굵게, 2줄 허용): **How Students Commuted to School in 2015 and 2025**
- 범례(오른쪽 위 작은 상자): 진한 회색 = **2015**, 연한 회색 = **2025**
- 가로축에 범주 5개(왼쪽부터), 범주마다 막대 2개(왼쪽 2015, 오른쪽 2025):

  | 범주 | 2015 | 2025 |
  |---|---|---|
  | Walking | 34 | 28 |
  | Bus | 26 | 24 |
  | Car | 18 | 22 |
  | Bicycle | 8 | 15 |
  | Subway | 14 | 11 |

- 세로축: 0, 10, 20, 30, 40 눈금 숫자, 축 위에 **(%)**. 막대 높이는 수치에 **정확히 비례**.
- 각 막대 위에 수치를 작은 숫자로 표기(34, 28, 26, 24, 18, 22, 8, 15, 14, 11).
- 검수 포인트: 범주 이름 철자·순서, 10개 수치 라벨, 막대 높이 비율(예: 34 막대 = 8 막대의 4.25배), 범례 색 구분.
